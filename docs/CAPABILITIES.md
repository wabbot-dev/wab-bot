# Capabilities

What WAB bot supports today, what it does not, and what is planned. "Planned" is not a date or a promise. How each item was verified: [STATUS.md](STATUS.md).

| Area | Supported | Not supported | Planned |
|---|---|---|---|
| **Messaging** | Receive WhatsApp text (signature-checked, de-duplicated) and store it per conversation; an AI agent over MCP reads the history and replies through guarded tools; the 24-hour window rule; approved templates from your allowlist, with header and dynamic buttons; documents, images, reply buttons and lists in replies ([OUTBOUND.md](OUTBOUND.md)); staff console (pause, take over, release, resolve, erase); content-free wake of your agent with retry; read receipts and typing indicator; retry after Meta rate limits; instant owner alerts on escalation ([ALERTS.md](ALERTS.md)); retention and per-conversation erase; voice notes transcribed, images described and PDF/Office documents read with Workers AI inside the free daily allowance, locations and contact cards read, with a plain fallback marker ([MEDIA.md](MEDIA.md)); optional voice-note replies, off by default, with Arabic and other languages through an optional xAI or ElevenLabs provider ([VOICE-REPLIES.md](VOICE-REPLIES.md)); optional business mode with an owner account directory, staff-verified payments and a bookings/orders hook ([BUSINESS-MODE.md](BUSINESS-MODE.md)) | Video understanding (noted with its caption only); stickers are noted, not described; groups; catalog and flow messages | A settings page; preset routines by business type |
| **Voice calls** | Inbound WhatsApp calls answered by a Grok Voice agent (Meta SIP to xAI SIP); owner gate, short arm windows, auto-disarm; caller allowlist, per-call time cap, monthly budget; call log and text transcripts of both sides (on by default, 30 days, erasable); live-tested in English and Arabic | Outbound calls; recording audio; other SIP voice agents are selectable (`CALL_SIP_TARGET`) but untested; custom (cloned) voices | A run on a business-verified production number |
| **Numbers and accounts** | One business and one WhatsApp Cloud API number per deployment, with your own Meta app, tokens, Cloudflare account and xAI account | Numbers registered in a WhatsApp app (coexistence); several businesses in one deployment; using Meta's Graph calling endpoints on a number that uses SIP (the two are mutually exclusive per number) | Not planned |
| **Operations** | Deploy to your own Cloudflare account (API route run live; wrangler route run live once with an API token); owner-only admin MCP (status, setup check, redacted conversations, arm and disarm calling, call logs, usage, update check); self-provisioned secrets; teardown scripts | Hosting for other people's businesses | Running the interactive wrangler login route live; testing the admin MCP with real MCP clients |

Reading the table: **Supported** means implemented and tested locally, and for the messaging round trip and the voice-call items listed above also run live on Meta's test number. Everything is bounded by Meta's rules (Business Verification for a business number, per-number limits) and by your own plans with Cloudflare, Meta and xAI. See [VOICE-CALLS.md](VOICE-CALLS.md) for calling details and [ROADMAP.md](ROADMAP.md) for the full list of open items.
