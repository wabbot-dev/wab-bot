# Configuration reference

Endpoints, MCP tools, send guards and environment variables. Names only: values belong in your own Worker secrets or `[vars]`, never in this repository. `.env.example` lists every name.

## Endpoints

| Route | Auth | Notes |
|---|---|---|
| `GET /` | none | health page, 200 `ok` |
| `GET /api/health` | none | liveness: 200 `{"ok":true,"version":"<package version>"}` only (no secret, count or message data; no storage read; `Cache-Control: no-store`). 405 for other methods except `HEAD` |
| `GET /api/webhook` | `hub.verify_token` = `WA_VERIFY_TOKEN` | Meta handshake: 200 echo of `hub.challenge`, else 403 |
| `POST /api/webhook` | `X-Hub-Signature-256` HMAC (`WA_APP_SECRET`) over the **raw body bytes**, constant-time compare | 200 `{ok:true}`, 401 invalid signature (no storage touched), 400 bad json, **503 + `Retry-After: 2`** if the store stayed contended for the whole ~8 s retry budget (nothing applied), 500 real store/config error. Meta redelivers on non-200; wamid dedupe makes redelivery idempotent |
| `POST /mcp` | `Bearer MCP_TOKEN` | stateless MCP over Streamable HTTP (JSON responses, no SSE, no sessions); `GET`/`DELETE` answer 405 after auth |
| `GET/POST /api/admin`, `/admin` page | `Bearer ADMIN_TOKEN`, or a staff session cookie (see below) | **team inbox**: static HTML (CSP, noindex); two panes (conversation list with search, a "Needs a human" queue and unread counts; chat bubbles with a reply box), works on a phone, refreshes every 10 s while the tab is visible ("Live" switch). Actions: `set_auto_reply`, `takeover`, `release`, `release_hold`, `reopen`, `resolve`, `wake`, `delete_conversation`, `reply` (staff reply: `text` or an allowlisted `template_name`, optional `idempotency_key`; moves the conversation to `human_takeover`), `opt_out`, `opt_in`, and `staff_invite` (owner token only; optional `ttl_minutes` 5-60, default 15) |
| `POST /api/staff/login`, `POST /api/staff/logout`, `GET /api/staff/session` | one-time invite code from `staff_invite` | redeems a single-use code (only its hash is stored) for an `HttpOnly; Secure; SameSite=Strict` session cookie valid 12 hours, signed with `ADMIN_TOKEN` (rotating it signs everyone out). A cookie session may read the inbox and use the conversation actions; changing requests also need the header `X-Staff-Request: 1`. It can never mint invites, start conversations or touch `/api/admin/secrets`. Staff never see the admin token |
| `POST /api/admin/start-conversation` | `Bearer ADMIN_TOKEN` | owner-run bot-started messages: the same function and guards as the MCP tool `start_conversation` |
| `POST /api/setup` | one-time `SETUP_NONCE` in the JSON body | **self-provisioning:** stores `secrets` in the Durable Object and locks forever. 200 once; every later call 403; 400 on a bad body (nothing claimed); never echoes values. See "Self-provisioning secrets" |
| `GET/POST /api/admin/secrets` | `Bearer ADMIN_TOKEN` | names and sources only (GET); rotate or delete a stored value (POST) |
| `GET/POST /api/admin/meta-setup` | `Bearer ADMIN_TOKEN` | **404 unless the deployment variable `META_SETUP_ENABLED` is exactly `1`** (any other value, including `true`, keeps it off; it is not a managed secret, so `/api/setup` and `/api/admin/secrets` cannot turn it on). Prefer `scripts/meta-setup.mjs` on your own computer |
| `DELETE /api/admin/conversations/<id>` | `Bearer ADMIN_TOKEN` | **erase one conversation** (customer number, profile name, message text, reply records, wake log, lease) in one commit. 200 `{ok:true,deleted:true}`, 400 malformed id, 401, 404 unknown id (also on a second call), 405 other methods. Same effect as the admin action `delete_conversation`. See [PRIVACY.md](PRIVACY.md) |
| `POST /admin/mcp` | `Bearer ADMIN_MCP_TOKEN` (>= 32 chars) | **owner-only admin MCP** (14 tools, Streamable HTTP, stateless). **404 unless the secret binding `ADMIN_MCP_TOKEN` is set.** 401 bad token, 403 foreign `Origin`, 429 rate limited. See [mcp.md](mcp.md) |
| `POST /api/xai-sip` | Standard Webhooks signature from xAI, over the raw body | **voice calling webhook. 404 unless the owner gate is open** (`CALLING_MODE` is `test` or `live`); 401 unless a calling window is armed and the signature is valid. See [VOICE-CALLS.md](VOICE-CALLS.md) |
| `POST /api/admin/media-selftest` | `Bearer ADMIN_TOKEN` only (no staff cookie) | **404 unless the variable `MEDIA_SELFTEST` is exactly `1`.** Body = a sample audio or image file; query `kind=audio\|image`, optional `voice=1`, `caption=`, `via=graph` (upload to the number's own Meta media store, then download by media id). Runs the voice-note/image path into a self-test conversation (fake number `15550100099`) without waking the agent; answers status codes only ([MEDIA.md](MEDIA.md#owner-self-test-route)) |
| `POST /api/admin/voice-selftest` | `Bearer ADMIN_TOKEN` only (no staff cookie) | **404 unless `MEDIA_SELFTEST` is exactly `1`.** Body = a reply text; query `lang` (two letters), optional `upload=1`, `audio=1`, `where=worker`, or `send=1&to=<digits>` (one real voice reply to a `TEST_RECIPIENTS` number in test mode, on an erased self-test conversation). Status, sizes and timings only ([VOICE-REPLIES.md](VOICE-REPLIES.md#owner-self-test-route)) |
| `GET /api/cron/retry-wakes` | `Bearer CRON_SECRET` | manual trigger; the daily Cron Trigger calls the same retry pass directly |

Bearer secrets must be >= 16 characters (shorter or unset refuses everything), compared in constant time.

### MCP tools (each returns one JSON text block)
`list_pending`, `claim_conversation`, `get_history` (limit 1-50, default 20; customer text wrapped in `<untrusted_customer_text>`, including voice-note transcripts and image descriptions, which also carry `media: {status, language}`; [MEDIA.md](MEDIA.md)), `send_reply` (no `to` field; text <= 4000 or `template_name`, optional `template_language`, `template_params`, `idempotency_key`, and for optional voice-note replies `reply_as` (`auto`/`text`/`voice`) and `voice_language`; the result adds `sent_as` and, after a fallback to text, `voice_fallback`; [VOICE-REPLIES.md](VOICE-REPLIES.md)), `finish_conversation`, `release_conversation`, `escalate_conversation` (reason 1-500), `get_controls`, `get_overview`, `start_conversation` (bot-started message, no lease, `idempotency_key` required; guards below). No tool can change global controls. A store that stays busy yields `{"ok":false,"error":"store_busy","retryable":true}` (nothing applied; call again). Invalid arguments are JSON-RPC error -32602.

**`get_overview`** (no arguments, read-only; Bearer `MCP_TOKEN`, so a routine needs no admin token): one JSON block with `conversations` (`total`, `by_state` for `pending`/`claimed`/`replied`/`held_for_review`/`escalated`/`human_takeover`, `oldest_pending_age_seconds` + `oldest_pending_conversation_id`, `last_inbound_at`), `wake` (`failed_count`, `scheduled_count`, `earliest_next_retry_at`, `url_configured`, `key_present`, `auth_mode`, `debounce_ms`), `controls` (`launch_mode`, `auto_reply`, and only COUNTS for `TEST_RECIPIENTS`, `WA_TEMPLATE_ALLOWLIST`, `WA_PHONE_NUMBER_IDS`, plus `meta_setup_enabled`), `rejections` (bad-signature counter), `media` (voice-note/image switches, caps, models, `ai_binding_present`, counters for today (UTC) and in total: `transcribed`, `described`, `too_large`, `download_failed`, `ai_failed`, `ai_quota_exhausted`, `ai_paid_only`, `unavailable`, `audio_seconds`, vision tokens; for voice replies `voice_replies`, `voice_tts_model`, `voice_languages`, `voice_speaker_present`, `voice_max_chars`, `voice_max_seconds` and the counters `voice_sent`, `voice_fallback`, `voice_tts_failed`, `voice_encode_failed`, `voice_upload_failed`, `voice_language_unsupported`, `voice_send_rejected`, `voice_seconds`, `voice_chars`; `estimated_neurons_today`, `free_neurons_per_day`, `last_failure_at`, `last_failure_code`; never content, see [MEDIA.md](MEDIA.md#fallbacks-and-counters)) and `secrets` (`setup_locked`, `present` / `missing` lists and the NAME -> `{source: env|stored|unset, kind: secret|setting}` map). It never returns message text, customer names or numbers, conversation leases, secret values, `WAKE_URL`, or the contents of any list-type setting, and it cannot change anything (it takes no input that is used). Cost: one store read (same as the admin overview), zero writes. An expired lease counts as `pending`, like `list_pending`. If the credential-name lookup fails, `secrets` is `null` and the rest is still returned.
The MCP endpoint is hand-written (initialize, ping, tools/list, tools/call) rather than built on an SDK, to keep per-request CPU low; it has been tested with direct JSON-RPC calls only, **not with real MCP clients**.

### `send_reply` guards, in order (exact `error` strings)
1 `not_found` -> 2 `blocked_human_takeover` -> 3 `blocked_held_for_review` -> 4 `lease_invalid_or_expired` -> 5 `unseen_inbound_messages` (+ `hint`, `unseen_messages[]`) -> 6 `blocked_auto_reply_paused` -> 7 `blocked_test_mode_recipient_not_allowlisted` (when `LAUNCH_MODE` is not `live`) -> 8 `template_not_allowlisted` | `empty_text` / `text_too_long` / `blocked_24h_window_closed_use_allowlisted_template` -> 9 idempotency: `ok:true idempotent_replay` / `previous_attempt_failed_definitively_use_new_idempotency_key` / `uncertain_previous_send_held_for_review` -> 10 `rate_limited_conversation` (5 per 10 min) -> 11 `not_configured_access_token_missing` -> 12 `concurrent_send_same_key` -> 13 `rate_limited_global` (60 per UTC hour) -> 14 lease + unseen re-checked atomically while reserving the slot -> 15 Meta 4xx (not 408/429): `send_rejected_http_{status}` (+ `meta_error_code`) -> 16 timeout (15 s) / 5xx / 408 / 429 / 2xx without wamid: `send_uncertain_held_for_review` (conversation becomes `held_for_review`, **never resent**).

### `start_conversation` guards (exact `error` strings; all checked before any Meta call, and again inside the reserve commit)
For a reminder the customer asked for or a follow-up on an open case, never marketing. Arguments: `conversation_id` OR `to` (digits; needs `WA_WABA_ID` and the first `WA_PHONE_NUMBER_IDS` entry), `text` OR `template_name` (+ `template_language`, `template_params`), and a REQUIRED `idempotency_key` (stable per reminder).
`idempotency_key_required` -> `give_conversation_id_or_to` -> `template_not_allowlisted` / `empty_text` / `text_too_long` -> `invalid_to` / `not_configured_waba_id_or_phone_number_id` -> `not_found` -> `blocked_no_prior_inbound` (the number never wrote in and is not on `OUTREACH_ALLOWLIST`) -> `blocked_human_takeover` / `blocked_held_for_review` / `blocked_escalated` / `conversation_active_use_send_reply` (state `pending` or `claimed`) -> `blocked_opted_out` -> `blocked_auto_reply_paused` -> `blocked_test_mode_recipient_not_allowlisted` -> `blocked_24h_window_closed_use_allowlisted_template` -> idempotency (same as `send_reply`) -> `rate_limited_conversation` -> `not_configured_access_token_missing` -> `concurrent_send_same_key` -> `rate_limited_global` -> then the same Meta outcomes as `send_reply` (`send_rejected_http_{status}`, `send_uncertain_held_for_review`). On success: `{ok:true,status:"sent",reply_key,conversation_id}`. The conversation state does not change. `send_reply`, `start_conversation` and staff replies share one delivery function and the same rate slots.

### Opt-out (STOP / START)
An inbound text, button or interactive message that is exactly `STOP`, `UNSUBSCRIBE`, `ARRET`, `ARRÊT` or `إيقاف` (trimmed, case-insensitive, trailing `.`/`!` ignored) sets the conversation's opt-out; `START` clears it. The message is still stored and still wakes the agent, so it can confirm once; `send_reply` to a customer who just wrote stays allowed; every bot-started message is refused (`blocked_opted_out`). Staff can set or clear it in the inbox (`opt_out`, `opt_in`). Shown as `opted_out` in `get_history`, `get_controls`, the admin conversation view and list; `get_overview` counts `conversations.opted_out`.

## Configuration (names only; see `.env.example`)

Secrets (`wrangler secret put`, **or** self-provisioned through `POST /api/setup`, see [SELF-PROVISIONING.md](SELF-PROVISIONING.md); a real binding wins over a stored value): `WA_ACCESS_TOKEN`, `WA_APP_SECRET`, `WA_VERIFY_TOKEN`, `MCP_TOKEN`, `ADMIN_TOKEN`, `CRON_SECRET`, `WAKE_KEY`, `XAI_API_KEY` (voice calling), and `WAKE_URL` if it embeds a key. `ADMIN_MCP_TOKEN` is a secret too but is **not** self-provisionable: set it yourself ([mcp.md](mcp.md)). Plain settings may go in `[vars]` in `wrangler.toml`.

| Name | Purpose |
|---|---|
| `WA_PHONE_NUMBER_IDS` | **Required.** The phone number ids this deployment serves, comma separated. Empty = **no** number is answered (fail closed; the setup route stores the setup number). `*` = any number on the Meta app (only when one bot serves the whole app) |
| `WA_TEMPLATE_ALLOWLIST` | approved template names the agent may send (empty = none) |
| `WA_WABA_ID` | your WhatsApp Business Account id: lets `start_conversation` address a number by `to`, and lets the admin MCP `setup_check` read the WABA's subscribed apps (read-only) |
| `WA_APP_ID` | optional: your Meta app id, so `setup_check` confirms that exactly your app is subscribed to the WABA |
| `OUTREACH_ALLOWLIST` (owner-only binding; never self-provisioned) | digits, comma separated, empty by default: numbers a bot-started message may reach before they ever wrote in (still template-only, test mode, opt-out and rate limits apply) |
| `GRAPH_VERSION` | default `v25.0` |
| `LAUNCH_MODE`, `TEST_RECIPIENTS` | `live` or test (default test); numbers allowed in test mode |
| `WAKE_URL` (**https only**, `http://localhost` for dev), `WAKE_KEY`, `WAKE_HEADER`, `WAKE_AUTH` (`bearer`/`header`) | where the content-free wake goes |
| `WAKE_DEBOUNCE_MS` (0-25000, default 3000), `WAKE_TYPES` | wake timing (the reply delay after the first message of a burst) and which inbound types wake |
| `LEASE_MS`, `RATE_CONV_MAX` (default 8), `RATE_CONV_WINDOW_MS` (default 10 min), `RATE_GLOBAL_PER_HOUR` (default 300), `SEND_TIMEOUT_MS`, `MAX_MESSAGES`, `STALE_WAKE_MS` | tuning (defaults in `lib/config.ts`). The bridge's own limits sit well below Meta's (80 messages per second per number; about one message every 6 s to the same user) |
| `SEND_RETRIES` (0-4, default 2), `SEND_RETRY_BASE_MS` (default 1000) | after a rate-limited send (HTTP 429 or Meta codes 4, 80007, 130429, 131056) the bridge waits 1 s, then 3 s, and tries again; still limited = `send_rate_limited` (nothing sent, `retryable: true`), never held for review |
| `READ_RECEIPTS`, `TYPING_INDICATOR` (default on) | when the agent claims a conversation it may answer (live mode, or an allowlisted test recipient), the customer's latest message gets blue ticks and "typing..." (Meta removes it when the reply arrives or after 25 s). `0` turns either off |
| `SETUP_NONCE` (plain-text var, not a secret) | one-time key for `POST /api/setup`; >= 32 chars; unset or short = setup disabled |
| `META_SETUP_ENABLED`, `META_SETUP_DRY_RUN` | meta-setup route gate (default off) and its offline stub |
| `MEDIA_TRANSCRIBE`, `MEDIA_DESCRIBE` (default **on**; `0`/`false`/`no`/`off` = off) | transcribe inbound voice notes / describe inbound images with Workers AI (the `AI` binding in `wrangler.toml`); off = type and caption only, as before ([MEDIA.md](MEDIA.md)) |
| `MEDIA_MAX_AUDIO_SECONDS` (5-600, default 120), `MEDIA_MAX_AUDIO_BYTES` (default 2000000, max 16 MB), `MEDIA_MAX_IMAGE_BYTES` (default 3000000, max 5 MB), `MEDIA_TIMEOUT_MS` (2000-20000, default 18000) | caps: anything larger is skipped with a marker and no model call; Workers AI call timeout |
| `MEDIA_STT_MODEL`, `MEDIA_VISION_MODEL` | Workers AI model names (default `@cf/openai/whisper-large-v3-turbo`, `@cf/meta/llama-4-scout-17b-16e-instruct`) |
| `MEDIA_SELFTEST` | `1` mounts the owner-only `POST /api/admin/media-selftest` and `POST /api/admin/voice-selftest` (default off: 404) |
| `VOICE_REPLIES` | Optional voice-note replies ([VOICE-REPLIES.md](VOICE-REPLIES.md)): `off` (default), `mirror` (recommended: speak only when the customer's latest message was a voice note) or `on` (also on `reply_as: "voice"`) |
| `VOICE_TTS_MODEL` | Workers AI text-to-speech model (default `@cf/myshell-ai/melotts`: English, French, Spanish, Chinese, Japanese, Korean; no Arabic, see `VOICE_REPLY_PROVIDER`) |
| `VOICE_MAX_CHARS`, `VOICE_MAX_SECONDS`, `VOICE_TIMEOUT_MS` | Caps (default 400 characters, 45 s of audio) and the text-to-speech timeout (default 15000 ms); over a cap the text is sent |
| `VOICE_REPLY_PROVIDER` | `workers-ai` (default), `xai` (your xAI key, as for calls) or `elevenlabs` (your ElevenLabs voice): Arabic, and languages the Workers AI model lacks, are spoken by that provider ([VOICE-REPLIES.md](VOICE-REPLIES.md#arabic-and-other-languages-xai-or-elevenlabs)) |
| `BUSINESS_MODE`, `BOT_LANGUAGE` | `consumers` (default), `businesses` or `both`; `auto` or preferred language codes ([BUSINESS-MODE.md](BUSINESS-MODE.md)) |
| `IDENTITY_CHECK`, `CUSTOMER_DETAILS` | `none` / `known_number` / `details`; fields the agent collects before orders and account requests |
| `PAYMENT_CHECK` | `staff`: staff-verified payment claims (default off) |
| `BOOKING_WEBHOOK_URL`, `BOOKING_WEBHOOK_KEY` (secret) | The bookings/orders hook and its Bearer key |
| `CALL_SIP_TARGET` | `xai` (default) or another voice agent's SIP `host[:port]` ([VOICE-CALLS.md](VOICE-CALLS.md#another-voice-agent-callsiptarget)) |
| `OUTBOUND_MEDIA_HOSTS` | If set, documents and images sent by URL must come from these hosts ([OUTBOUND.md](OUTBOUND.md)) |
| `ALERT_WEBHOOK_URL`, `ALERT_WEBHOOK_KEY` (secret) | Instant alert webhook (https) and its Bearer key ([ALERTS.md](ALERTS.md)) |
| `ALERT_WHATSAPP_TO`, `ALERT_TEMPLATE`, `ALERT_TEMPLATE_LANGUAGE` | Owner/staff numbers for WhatsApp alerts; approved template (one body parameter), language (default `en`) |
| `ALERT_EVENTS`, `ALERT_ADMIN_URL` | Which events alert (default all: `escalation`, `payment_claimed`, `booking_failed`, `test`); admin link in the webhook body |
| `XAI_TTS_VOICE`, `XAI_TTS_ARABIC_LOCALE` | xAI voice (default `eve`, or a custom voice id) and Arabic locale (`ar-EG`, `ar-SA`, `ar-AE`; default from the dialect preset) |
| `ELEVENLABS_API_KEY` | Secret (stdin only). ElevenLabs key scoped to Text to Speech plus Voices read; sent only to `api.elevenlabs.io` |
| `ELEVENLABS_VOICE_ID`, `ELEVENLABS_MODEL_ID`, `ELEVENLABS_MAX_CHARS` | The voice; the model (default `eleven_v4`); the cap (default 600 characters, longer replies go as text) |
| `VOICE_STYLE_TAG` | Optional direction for tag-aware ElevenLabs models (`eleven_v3` / `eleven_v4`), e.g. `warm, friendly`; unset = none |
| `VOICE_PRONUNCIATIONS` | Optional `written => spoken` list applied to the spoken copy only ([VOICE-REPLIES.md](VOICE-REPLIES.md#pronunciation-list)) |
| `ARABIC_REPLY_DIALECT` | `none` (default), `msa`, `lebanese`, `gulf` or `egyptian`: the wording hint `get_history` gives the agent for spoken Arabic replies ([VOICE-REPLIES.md](VOICE-REPLIES.md#arabic-dialect-presets)) |

### Admin MCP and voice calling (bindings and vars; none of the gate settings can be set through any route or tool)

| Name | Purpose |
|---|---|
| `ADMIN_MCP_TOKEN` (secret) | enables `/admin/mcp`; >= 32 chars; unset = route is 404 |
| `XAI_API_KEY` (secret) | your own xAI key; calling only |
| `CALLING_MODE` | **owner gate.** `off` (default), `test` (answers only `CALL_ALLOWED_CALLERS`), `live` (needs the next two) |
| `CALLING_BV_DONE` | live only: `1` = you attest Meta Business Verification is complete |
| `CALLING_GO_NUMBER` | live only: digits of the one number you approve for calling |
| `CALLING_PHONE_NUMBER_ID` | which WhatsApp phone number id to arm (default: first of `WA_PHONE_NUMBER_IDS`) |
| `CALL_ALLOWED_CALLERS` | caller numbers (digits, comma separated) the agent answers; required in test mode |
| `CALL_MAX_SECONDS` (10-600, default 120 seconds per call), `CALL_BUDGET_SECONDS` (default 1200 seconds per UTC month) | spend caps; about $0.08 per minute at xAI, paid by you |
| `CALL_VOICE`, `CALL_LANGUAGE_HINT`, `CALL_DISCLOSE_AI` (default off), `CALL_RECORDING_LINE` (default off), `CALL_SIP_WEBHOOKS` (default off; test aid: SIP call webhooks on, logged by type and call id only), `CALL_BUSINESS_NAME`, `CALL_GREETING`, `CALL_INSTRUCTIONS` | the voice agent's persona and disclosure ([VOICE-CALLS.md](VOICE-CALLS.md)) |
| `CALL_TRANSCRIPTS` (default **on**; `0`/`false`/`no`/`off` = off), `CALL_TRANSCRIPT_RETENTION_DAYS` (1-365, default 30) | keep a text transcript of each call in your own Durable Object, expiring after the retention days. Never audio ([VOICE-CALLS.md](VOICE-CALLS.md#what-is-logged-and-stored)) |

Arm window limits (fixed in code): 1 to 60 minutes, 1 to 5 calls. The Worker also needs the `CALLS` Durable Object binding and migration `v2`, which `wrangler.toml` already declares; a Worker deployed before calling existed needs `--migrate-from v1` on `scripts/cf-api-deploy.mjs deploy` ([DEPLOY.md](DEPLOY.md)).
